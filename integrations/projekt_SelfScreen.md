# Projekt SelfScreen
- **Was:** Konfigurierbare Custom-Firmware für die GeekMagic SmallTV-Ultra (ESP8266): rotierende Screens (Uhr, Wetter u. a.). GitHub: `s3lfcod3r/SelfScreen` (öffentlich).
- **Arbeitsordner:** `Github SelfCoder/selfscreen` (Git-Klon, Container `/repos/selfscreen`).
- **Automatische Commits:** die Aktionen `build.yml`, `docs.yml` und `quotes.yml` committen selbst (am 01.10.2026 gab es neue Pushes). **Immer erst `gitpull`**, bevor du arbeitest oder pushst.
- **Grenzen:** Firmware bauen und auf das Gerät flashen kannst du nicht (braucht USB-Zugriff am PC). Änderungen im Code prüfen und die Bauaktion auf GitHub auswerten; geflasht wird von Sven.
- **Version:** Stellen (Firmware-Version im Code, README, Release) bei der ersten Prüfung ermitteln und hier eintragen.
- **Nie:** den Arbeitsordner verschieben, ersetzen, klonen oder löschen. Kein Push und kein Release ohne ausdrücklichen Auftrag von Sven. Nach Zugangsdaten suchen (Passwörter, Tokens, Schlüssel), bevor etwas veröffentlicht wird. Keine Schlüsseldateien (`*.jks`, `keystore.properties`) committen.
